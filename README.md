# Used-Car-Price-Prediction

**Used Car Price Prediction** is a machine learning project that estimates the selling price of a used car based on its features and market data. The model analyzes factors such as the car's brand, model, manufacturing year, fuel type, transmission type, kilometers driven, ownership history, engine capacity, mileage, and other specifications to predict a fair market value.

The project involves collecting and preprocessing data, performing Exploratory Data Analysis (EDA), feature engineering, encoding categorical variables, selecting important features, training machine learning models, and evaluating their performance using metrics such as Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and R² Score. Common algorithms used include Linear Regression, Decision Tree, Random Forest, XGBoost, and Gradient Boosting.

The primary objective of this project is to provide accurate price estimates that help buyers make informed purchasing decisions and assist sellers in setting competitive prices. It also enables dealerships and online automobile marketplaces to automate vehicle valuation, improve transparency, and reduce pricing errors. By leveraging historical data and machine learning techniques, the system delivers reliable and data-driven used car price predictions.
